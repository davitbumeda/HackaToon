# 🚀 HackaToon - Ideias Malucas. Código de Verdade.

> *Junte criatividade, tecnologia e uma boa dose de diversão. No HackaToon, sua próxima grande ideia pode sair do rascunho e ganhar vida.*

---

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento da landing page oficial para o **HackaToon**, um evento focado em unir criatividade, código e inovação. A plataforma visa fornecer informações centralizadas sobre o evento, cronograma, desafios e um sistema seguro para inscrição de participantes.

Este repositório foi desenvolvido como parte de uma atividade acadêmica da faculdade.

---

## 🎨 Layout e Protótipo

A interface web foi planejada com uma identidade visual moderna e descontraída, destacando as seções principais:
- **Navegação principal:** O Evento, Desafios, Como Funciona, FAQ.
- **Chamadas para Ação (CTA):** Botões diretos para inscrição de participantes.
- **Informações Gerais:** Datas, local e status de inscrições.

---

## 🛠️️ Tecnologias Planejadas

O projeto está estruturado para utilizar tecnologias modernas e acessíveis para a construção e publicação do site:

- **Front-end:** HTML5, CSS3 e JavaScript.
- **Banco de Dados:** MySQL.
- **Hospedagem & Deploy:** GitHub Pages, Railwai.

---

## 🔒 Segurança do Banco de Dados

Atendendo aos requisitos acadêmicos e de privacidade, a arquitetura do banco de dados prioriza a segurança das informações dos participantes através das seguintes práticas:

- **Proteção de Dados Pessoais:** Criptografia para dados sensíveis (ex: senhas e dados de cadastro).
- **Prevenção a Injeções de Código:** Consultas preparadas (*Prepared Statements* / ORM) para evitar vulnerabilidades de *SQL Injection*.
- **Controle de Acesso:** Princípio do menor privilégio para credenciais de acesso ao banco.
- **Variáveis de Ambiente:** Credenciais e chaves de conexão isoladas e nunca expostas publicamente no código fonte (`.env`).
